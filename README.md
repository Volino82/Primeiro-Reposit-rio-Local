# Utilização de Markdown

## Formatação de texto

- Itálico: *texto*
- Negrito: **texto**
- Taxado: ~~texto~~
- Combinar: __*texto*__

## Linha de Separação
Utilizar três traços ---
Os títulos possuem linhas automáticas

## Listas e Marcadores

### Lista
1. nivel 1
    1. nível 2
        1. nível 3
    1. nível 2
        1. nível 3
1. nível 1

### Marcadores
* nivel 1
    * nível 2
        - nível 3
- nível 1

## Lista de tarefas
- [x] Completo
- [ ] Incompleto

(No VSCode o visualizador de markdown não mostrou a configuração do marcador de tarefas)

## Código

### Comando
O comando `print()` é utilizado para escrever no terminal  

### Trecho em Python
```
n = Int(Input('Digite um número: "))
if n % 2 == 0
    print(f'{n} é par!')
else
    print(f'{n} não é par!')
```
